## Behavior

Message rows are keyboard focusable. Focusing a row creates its existing lazy
Reply/Copy controls; Tab then reaches the buttons, and Enter/Space activates
them. Focus outlines identify the current row/button. A touch pointerup focuses
the tapped message body without scrolling; taps on links/buttons retain their
normal behavior. Coarse-pointer devices use at least 44×44px action targets.
Mouse hover and existing platform-specific reply/send rules remain in place.
Messages add tab stops in feed order; the feed remains bounded by its setting.

The installed-update page now has 1.23.14 as its first LATEST UPDATE section,
with the previously missed 1.23.12 and 1.23.13 notes restored below it. No
installation listener, notification storage key or open-once logic changed.

The full suite's existing `releasenotes` target now requires a first section
matching manifest.version, exactly one LATEST UPDATE marker in that section,
and a nonempty list of changes. It tests rejection of missing/stale/misplaced/
blank entries, missing headings, duplicate markers and version-prefix mistakes.
The release workflow already runs this full suite before packaging/signing/
publication, so future version bumps without bundled notes fail that gate.
