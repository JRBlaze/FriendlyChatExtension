Kick sign-in

The default reuses the redirect the Friendly Chat desktop app already registers with the same Kick application, so nothing needs setting up — no local server has to be running either. The other two are tidier but each needs a URL registered with Kick first; the overlay shows which.

Channel links

How each channel was matched to its counterpart on the other platform. Links found automatically expire after six hours; ones you set by hand are kept until you remove them.

Chat is read anonymously — no sign-in is needed to watch. Connecting an account is optional, and only buys you sending: without one, a typed message is handed to the chat box of the site you are on and goes out as whoever is signed in there. Account tokens are kept in this browser's local storage and are never synced across devices. Connect or disconnect an account from the overlay's own settings panel.
